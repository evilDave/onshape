# Helix start is part-studio −X; kept Die uses the start frame

The cylinder or cone seam is not a stable angle. Every generation frame uses the projection of part-studio −X onto the plane perpendicular to the thread axis (falling back to −Y). Keep builds the Die from that same start frame as apply, with the end chamfer at the End, instead of a far-end frame whose X was the helix phase at that length. A second phase origin was clocking the kept Die against the thread when depth changed.
