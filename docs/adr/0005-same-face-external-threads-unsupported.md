# Same-face External threads on one body are unsupported

A vertex or mate Location Die still grows to the owner's extent so a point on a plate becomes a pin. Several External threads named that way on the same face of one body are unsupported: that growth removes the sibling pins. Several Internal threads on the same face are fine. Pins on different bodies, or on different faces of the same body, stay in scope. A Location that is itself a cylindrical, conical, or pin end face is the exception: see 0006.
