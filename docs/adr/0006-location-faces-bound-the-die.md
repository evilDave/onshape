# Location faces bound the Die to that face

A Location may be a cylindrical or conical face or a pin or boss end face, as well as a vertex or mate connector, so similar holes or pins can be picked together. The tool is placed on that face's axis. A Die grows only to that face, so several External threads on one body stay in scope. Vertex and mate Locations still grow the Die to the owner so a point on a plate becomes a pin (ADR-0005).
